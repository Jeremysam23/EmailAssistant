# Intelligent Email Assistant using Ollama

## Overview
A Python-based AI Email Assistant that analyzes customer emails, detects their intent, and generates professional suggested replies using the locally running Llama 3.2 model through Ollama.

## Features
- Customer email input
- AI-based email intent detection
- Professional reply generation
- Context from previous email interactions
- Save generated replies to a local text file
- Continuous interactive usage

## Technologies
- Python
- Ollama
- Llama 3.2

## Requirements
- Python 3
- Ollama
- Llama 3.2 model

## Run
1. Install Ollama and download the model:
   `ollama pull llama3.2`
2. Run the application:
   `python3 main.py`

## Note
The assistant generates suggested replies. Review them before sending.
